## 三、核心技术结论与简历量化亮点

### 3.1 核心技术结论

1. **混合检索显著优于纯关键词检索**：在 30 道 Ground Truth 标注题上，`Hybrid RRF + Query Rewrite` 的 Recall@5 为 **90.00%**、MRR@5 为 **0.7233**，纯 `BM25 (无 Rewrite)` 分别为 **60.00%** 与 **0.5483**；Recall@5 提升 30.00 个百分点，MRR@5 提升 0.1750。
2. **Query Rewrite 对多轮指代追问有决定性增益**：`BM25 + Query Rewrite` 总体 MRR@5 为 **0.7650**，较无改写 BM25 提升 **0.2167**；规则实体补全可在无 LLM 的离线环境下稳定还原“他/那/这种/要回来”等指代背后的法律主题词。
3. **精确条号查询具备确定性直通能力**：RRF 精确条号 `+1.0` 直通加权使 `exact_article` 场景 五组实验的 Hit@1 均达到 **100.00%**，满足生产环境“问某条必回某条”的硬要求。
4. **确定性计算彻底消除大模型算术幻觉**：12 项金额/天数断言全部 **零误差通过**，覆盖 N / N+1 / 2N、三倍社平 12 年封顶、LPR 四倍红线截断、民事与劳动仲裁时效。
5. **ReAct Agent 具备工程级容错闭环**：工具参数畸形、字段缺失、未知工具均被封装为结构化错误回传模型，自愈重试成功率 **100%**；`max-iterations=4` 熔断后移除 `tools` 完成兜底回答，SSE 流不中断。

### 3.2 可直接复用的简历量化亮点

> 构建 30 题 Ground Truth 法律 RAG 离线评测集与 15 题 Agent 工具评测集，覆盖 5 部法规 144 条切片；通过 BM25 + 语义向量 RRF 混合检索与多轮 Query Rewrite，将 Recall@5 从 60.00% 提升至 90.00%、MRR@5 从 0.5483 提升至 0.7233；实现 12 类确定性法律计算断言 100% 零误差、Agent 工具异常自愈与 4 轮熔断 100% 通过，并落地 Token / TTFT / RAG 命中率 / 工具调用成功率可观测性看板。

**面试讲解要点：**

- 为什么需要 RRF：BM25 擅长法条号与精确术语，向量召回擅长口语同义与语义泛化，RRF 只依赖排名而非分数量纲，融合稳定且无需调参。
- 为什么需要 Query Rewrite：多轮追问常省略主体与法律关系，规则实体补全作为 LLM 改写兜底，保证离线、低延迟、可复现。
- 为什么金额必须工具化：LLM 对日期与金额的算术不稳定，`BigDecimal + LocalDate` 的确定性引擎可审计、可复算，是法律产品的合规底线。
